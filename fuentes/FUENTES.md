# Fuentes locales y licencias

- Familia: **Fraunces**, fuente variable, archivo original sin modificar.
- Autores: Undercase Type (Phaedra Charles y Flavia Zimbardi); créditos completos en la licencia incluida.
- Origen: https://github.com/google/fonts/tree/main/ofl/fraunces
- Archivo descargado: https://raw.githubusercontent.com/google/fonts/main/ofl/fraunces/Fraunces%5BSOFT%2CWONK%2Copsz%2Cwght%5D.ttf
- Licencia: **SIL Open Font License 1.1**, texto completo en `OFL-Fraunces.txt`. Permite incluir y redistribuir la fuente con el proyecto bajo sus condiciones.
- Uso actual: h3/h4, nombres de tarjetas de recetas, pestañas y algunos contadores. La marca y h1/h2 usan Alfa Slab One; lectura y controles usan fuentes del sistema. Georgia es alternativa de respaldo.

La app carga `Fraunces.ttf` desde esta carpeta mediante una ruta relativa. No consulta Google Fonts ni otro servicio; no requiere instalación o compilación.

## Alfa Slab One · uso actual

- Archivo original sin modificar: `AlfaSlabOne-Regular.ttf`.
- Autoría: JM Solé; copyright y condiciones completos en `OFL-AlfaSlabOne.txt`.
- Fuente: https://github.com/google/fonts/tree/main/ofl/alfaslabone
- Descarga: https://raw.githubusercontent.com/google/fonts/main/ofl/alfaslabone/AlfaSlabOne-Regular.ttf
- Licencia verificada: SIL Open Font License 1.1, permite redistribución y uso web mediante @font-face bajo sus condiciones. Se incluye el texto completo.
- Uso: marca Avanzi y títulos h1/h2, incluido el título del detalle. No es Kompot Slab: no se consiguió un archivo con licencia web verificable de esa familia. No se incorporan Jannah ni Anaphora.
- Se conserva Fraunces local para nombres de tarjetas y subtítulos h3/h4; lectura y controles usan fuentes del sistema. No hay conexiones a servicios de fuentes.

Los usos de versiones anteriores se conservan como historial en [CAMBIOS.md](../CAMBIOS.md); el diseño vigente está en [DISEÑO.md](../DISEÑO.md). Esta revisión solo actualiza este documento: archivos de fuentes y textos de licencia intactos.
